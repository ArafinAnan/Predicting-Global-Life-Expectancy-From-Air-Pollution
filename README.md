# Predicting Global Life Expectancy from Air Pollution 

A machine learning study investigating the impact of fine particulate matter ($PM_{2.5}$) and socio-demographic indicators on global life expectancy using a country-level dataset of 2,500 records[cite: 30, 31]. 

## Key Highlights
* **Models Evaluated:** Compared 10 regression algorithms including Linear Regression, Random Forest, Gradient Boosting, XGBoost, and a Neural Network (MLP)[cite: 30, 32].
* **Best Performance:** **XGBoost** achieved the highest accuracy with an $R^2$ of 0.963 and an RMSE of 1.79[cite: 30].
* **Tech Stack:** Python, Scikit-learn, XGBoost, Pandas, NumPy, Matplotlib, and Seaborn[cite: 32].
